## 1. Create an account

Open [router.triw.io](https://router.triw.io) and sign up with email or an enabled OAuth provider. After sign-in you land on the dashboard.

## 2. Top up your balance

New accounts start with whatever free quota the operator has configured. To add credit, go to **Dashboard → Top up** and choose a payment method, or redeem a code if you have one.

<Note>
Prices are per model and are shown on the [pricing page](https://router.triw.io/pricing). Billing is metered per request from the actual token usage returned by the provider.
</Note>

## 3. Create an API key

Go to **Dashboard → API Keys → Create key**, then set:

| Field | What it does |
| --- | --- |
| Name | Label for your own tracking |
| Group | Which upstream pool and price multiplier the key uses |
| Quota | Maximum spend this key may consume. Leave empty for "unlimited within your balance" |
| Expiry | Optional date after which the key is rejected |
| Allowed models | Optional allow-list; empty means all models available to the group |

Copy the key once (format `sk-...`) and store it as a secret. The console can show it again, but environment variables are safer.

## 4. Send a request

```bash
export TRIW_API_KEY="sk-..."   # your key
export TRIW_BASE_URL="https://router.triw.io"

curl "$TRIW_BASE_URL/v1/chat/completions" \
  -H "Authorization: Bearer $TRIW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "system", "content": "You are a concise assistant."},
      {"role": "user", "content": "What is a token?"}
    ],
    "stream": false
  }'
```

A successful call returns the standard OpenAI response object with `choices[0].message.content`.

## 5. Confirm which models you can use

```bash
curl "$TRIW_BASE_URL/v1/models" -H "Authorization: Bearer $TRIW_API_KEY"
```

The list is filtered by your key's group, so it reflects exactly what you are allowed to call. Route-by-route reference: [Endpoints](/endpoints). If a model is missing, the key's group does not include it — create a key in another group or ask the operator.
