Cline is an agent inside VS Code. It ships an **OpenAI Compatible** provider type, which maps directly onto Triw.

## Requirements

| Item | Note |
| --- | --- |
| VS Code | 1.84 or newer |
| Node | not required — the extension bundles its runtime |

## Install

1. Open VS Code → **Extensions** (`Cmd/Ctrl + Shift + X`).
2. Search **Cline**, install the publisher-verified extension.
3. Open the Cline panel from the sidebar; the API configuration screen appears on first run.

Alternative: install from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev) or the Open VSX registry for VSCodium.

## Configure

In the Cline panel, click the ⚙️ icon, then set:

| Field | Value |
| --- | --- |
| API Provider | `OpenAI Compatible` |
| Base URL | `https://router.triw.io/v1` |
| API Key | your `sk-...` Triw key |
| Model ID | exact id from `GET /v1/models`, e.g. `claude-sonnet-4-5` |

Then open **Model Configuration** and set the real limits of that model:

| Field | Why it matters |
| --- | --- |
| Context Window | Cline sizes its prompts from this; wrong values truncate or overrun |
| Max Output Tokens | Caps per-turn output |
| Supports Images | Enables screenshot input for vision models |
| Supports Computer Use | Enables the browser tool loop |
| Input / Output price | Local cost estimate in the UI only |

## Verify

Ask Cline to read a file in the open workspace. If it answers and the Triw log shows the request, the wiring is correct.

## Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| `400 invalid_request_error` | Model rejected a tool schema or parameter | Switch model; Cline's tool payload is large |
| Agent loops without progress | Weak tool-calling model | Use a coding model, raise max output tokens |
| Context errors after a few turns | Context window set too high | Set the model's real window |
| `401` | Key has quotes or a newline | Re-paste in the settings field |
