title: "CC Switch"
description: "Manage Triw as a provider profile across Claude Code, Codex, OpenCode and dsh."
---

CC Switch is a desktop app that stores provider profiles and writes them into each CLI's own config. One Triw profile can serve several tools.

## Requirements

| Item | Minimum |
| --- | --- |
| Windows | 10+ |
| macOS | 12 (Monterey)+ |
| Linux | glibc 2.35+ (Ubuntu 22.04+) with WebKitGTK 4.1 |

## Install

Download from [ccswitch.io/download](https://ccswitch.io/en/download) or the [GitHub releases](https://github.com/farion1231/cc-switch/releases). Install the package for your OS; no terminal step is required.

## Add Triw

1. Open CC Switch and pick the tool in the left sidebar (Claude Code, Codex, OpenCode, DeepSeek Harness…).
2. Click **+ Add Provider**, choose **Custom / Third-party** as the provider type.
3. Fill in:

| Field | Value |
| --- | --- |
| Name | `Triw` |
| Base URL | see the table below |
| API Key | your `sk-...` Triw key |
| Model | exact id from `GET /v1/models` |

4. Save, then activate the profile with the switch control for that tool.

## Base URL per tool

| Tool | Protocol | Base URL |
| --- | --- | --- |
| Claude Code | Anthropic Messages | `https://router.triw.io` |
| Codex | OpenAI Chat/Responses | `https://router.triw.io/v1` |
| OpenCode | OpenAI Chat | `https://router.triw.io/v1` |
| DeepSeek Harness | OpenAI Chat | `https://router.triw.io/v1` |

CC Switch writes the CLI config, so the tool keeps working with the app closed. Switching back to another provider is one click.

## Verify

Launch the CLI, ask a one-line question, then check Triw **Logs**. If the CLI reports unknown flags or 404, the base URL for that tool has the wrong shape — Anthropic tools take the host, OpenAI tools take `/v1`.

## Notes

- One provider entry per protocol: keep a `Triw` (host) and a `Triw v1` (with `/v1`) profile if you use tools from both families.
- Profiles store keys locally; use per-tool Triw keys so revocation stays surgical.
