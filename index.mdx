Triw is an AI gateway. You call one endpoint with one key, and Triw routes the request to the provider that serves the model you asked for. Billing, quotas, keys and usage all live in a single console.

```bash Base URL
https://router.triw.io
```

## How a request flows

1. You send a request to `https://router.triw.io` with an API key (`Authorization: Bearer sk-...`).
2. Triw resolves the model name to an available upstream channel for your key's group.
3. The upstream response is relayed back in the same wire format you sent.
4. Usage is metered against your balance.

You do not change your prompt or response parsing per provider — only the `model` value.

## First request

```bash
curl https://router.triw.io/v1/chat/completions \
  -H "Authorization: Bearer $TRIW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'
```
