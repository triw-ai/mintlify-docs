OpenCode adalah agent terminal dengan sistem provider berbasis config. Endpoint apa pun yang kompatibel OpenAI bisa dideklarasikan di `opencode.json` / `opencode.jsonc`.

## Kebutuhan sistem

| Item | Catatan |
| --- | --- |
| OS | macOS, Linux, Windows (disarankan WSL) |
| Node | 20+ bila instalasi lewat npm |

## Instalasi

<CodeGroup>
```bash skrip installer
curl -fsSL https://opencode.ai/install | bash
```
```bash npm
npm install -g opencode-ai
```
```bash Homebrew
brew install sst/tap/opencode
```
</CodeGroup>

```bash
opencode --version
```

## Konfigurasi

Config berada di `~/.config/opencode/opencode.jsonc` (global) atau `./opencode.json` (per proyek). Skema terbaru memakai objek `providers`:

```jsonc ~/.config/opencode/opencode.jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "triw": {
      "name": "Triw",
      "env": ["TRIW_API_KEY"],
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "https://router.triw.io/v1"
      },
      "models": {
        "claude-sonnet-4-5": { "name": "Claude Sonnet 4.5" },
        "gpt-4o-mini": { "name": "GPT-4o mini" }
      }
    }
  }
}
```

```bash
export TRIW_API_KEY="sk-..."
```

| Field | Fungsi |
| --- | --- |
| `env` | Daftar env var yang boleh menyimpan kredensial |
| `package` | Paket runtime untuk endpoint kompatibel OpenAI |
| `settings.baseURL` | Endpoint Triw |
| `models` | Id model yang ingin muncul di picker |

## Memilih model

Model dialamatkan sebagai `<provider>/<model>`:

```bash
opencode --model triw/claude-sonnet-4-5
```

Di dalam TUI, `/models` menampilkan yang Anda deklarasikan; `/connect` untuk provider katalog bawaan.

## Verifikasi

Minta sesuatu yang memerlukan tool call ("list file di direktori ini"), lalu pastikan entrinya muncul di **Logs** Triw.

## Troubleshooting

| Gejala | Penyebab | Perbaikan |
| --- | --- | --- |
| Provider tidak ada di picker | Kunci salah: `provider` bukan `providers` | Pakai objek `providers` |
| `Cannot find module` | Nilai `package` salah | Gunakan `@opencode/ai/providers/openai-compatible` |
| Id model ditolak | Id belum dideklarasikan di `models` | Tambahkan, atau salin id persis dari `/v1/models` |
| 404 di semua panggilan | `baseURL` tanpa `/v1` | `https://router.triw.io/v1` |
