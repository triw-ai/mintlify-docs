OpenClaw adalah gateway agent berbasis Node dengan katalog provider sendiri. Endpoint kustom dideklarasikan di `models.providers`.

## Kebutuhan sistem

| Item | Minimum |
| --- | --- |
| Node | 24.16+ pada seri 24.x, atau 26.1+ (disarankan 26) |
| OS | macOS, Linux, Windows (disarankan WSL) |
| Jaringan | HTTPS keluar ke `router.triw.io` |

## Instalasi

```bash
curl -fsSL --proto '=https' --tlsv1.2 https://openclaw.ai/install.sh | bash
openclaw --version
```

Installer menyediakan Node bila host belum punya. Windows: gunakan installer PowerShell dari [docs.openclaw.ai/install](https://docs.openclaw.ai/install).

## Konfigurasi

Deklarasikan Triw sebagai provider `openai-completions`, lalu arahkan model default agent ke sana:

```json5 ~/.openclaw/config.json5
{
  agents: {
    defaults: { model: { primary: "triw/claude-sonnet-4-5" } }
  },
  models: {
    providers: {
      triw: {
        baseUrl: "https://router.triw.io/v1",
        api: "openai-completions",
        apiKey: "${TRIW_API_KEY}",
        models: [
          { id: "claude-sonnet-4-5", name: "Claude Sonnet 4.5" },
          { id: "gpt-4o-mini", name: "GPT-4o mini" }
        ]
      }
    }
  }
}
```

```bash
export TRIW_API_KEY="sk-..."
```

Alternatif lewat onboarding:

```bash
openclaw onboard --custom-base-url https://router.triw.io/v1 --custom-model-id claude-sonnet-4-5
```

## Verifikasi

```bash
openclaw models list          # entri triw harus muncul
openclaw "balas dengan satu kata: ready"
```

Lalu pastikan panggilannya muncul di **Logs** Triw.

## Troubleshooting

| Gejala | Penyebab | Perbaikan |
| --- | --- | --- |
| Provider tidak muncul | `models.providers` ditaruh di file salah | Pakai `~/.openclaw/config.json5`, atau `~/.openclaw/agents/<id>/models.json` |
| Agent menjawab dari provider lain | `agents.defaults.model.primary` belum diarahkan | Set ke `triw/...` |
| `401` | `${TRIW_API_KEY}` tidak ter-resolve | Export variabelnya, atau tulis key langsung |
| Loop tool berhenti | Model tanpa dukungan tool | Pakai model coding |
