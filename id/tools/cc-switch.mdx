CC Switch adalah pengelola provider berbasis desktop: definisikan provider sekali, lalu tukar konfigurasi aktif untuk tiap CLI yang dikelolanya (Claude Code, Codex, OpenCode, DeepSeek Harness, dan lainnya).

## Menambahkan Triw

1. Buka CC Switch → pilih tool yang dikelola (mis. **Claude Code**).
2. **Add Provider**.
3. Isi:

| Field | Nilai |
| --- | --- |
| Name | `Triw` |
| Base URL | `https://router.triw.io` untuk tool gaya Anthropic, `https://router.triw.io/v1` untuk gaya OpenAI |
| API Key | key `sk-...` Anda |
| Model | id dari `GET /v1/models` |

4. Simpan, lalu **aktifkan** provider untuk tool tersebut.

CC Switch menulis config milik CLI-nya sendiri, jadi CLI tetap jalan tanpa aplikasi terbuka.

## Base URL per tool

| Tool | Protokol | Base URL |
| --- | --- | --- |
| Claude Code | Anthropic | `https://router.triw.io` |
| Codex | OpenAI | `https://router.triw.io/v1` |
| OpenCode | OpenAI | `https://router.triw.io/v1` |
| DeepSeek Harness | OpenAI | `https://router.triw.io/v1` |

Salah di sini menghasilkan `404` pada setiap panggilan karena path menjadi ganda.

## Verifikasi

Jalankan CLI dari terminal, ajukan satu pertanyaan pendek, lalu periksa log Triw. Kembali ke provider sebelumnya hanya satu klik bila ada masalah.
