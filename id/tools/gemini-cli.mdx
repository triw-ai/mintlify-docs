Gemini CLI adalah agent terminal dari Google. Ia memanggil Gemini REST API (`/v1beta`) yang juga disediakan Triw, dan menerima override base URL.

## Kebutuhan sistem

| Item | Minimum |
| --- | --- |
| Node | 20.0.0+ |
| OS | macOS 15+, Windows 11 24H2+, Ubuntu 20.04+ |
| RAM | 4 GB untuk pemakaian ringan, 16 GB untuk repo besar |

## Instalasi

<CodeGroup>
```bash npm
npm install -g @google/gemini-cli
```
```bash Homebrew
brew install gemini-cli
```
```bash npx (tanpa instalasi)
npx @google/gemini-cli
```
</CodeGroup>

```bash
gemini --version
```

## Konfigurasi

```bash
export GEMINI_API_KEY="sk-..."
export GOOGLE_GEMINI_BASE_URL="https://router.triw.io"
gemini
```

Atau simpan keduanya di settings pengguna:

```json ~/.gemini/settings.json
{
  "apiKey": "sk-...",
  "baseUrl": "https://router.triw.io"
}
```

`settings.json` mendukung substitusi environment (`"$MY_VAR"`), sehingga key tidak perlu ditulis langsung:

```json
{ "apiKey": "$TRIW_API_KEY" }
```

## Memilih model

```bash
gemini -m gemini-2.5-flash -p "bilang ready"
```

Hanya id `gemini-*` yang relevan untuk CLI ini. Keluarga model lain diakses lewat route kompatibel OpenAI.

## Verifikasi

Jalankan satu prompt, lalu cek **Logs** di console Triw. Log kosong berarti CLI masih memanggil Google — variabel base URL tidak sampai ke prosesnya.

## Troubleshooting

| Gejala | Penyebab | Perbaikan |
| --- | --- | --- |
| Panggilan tetap ke Google | `GOOGLE_GEMINI_BASE_URL` tidak ter-export di shell itu | Export sebelum `gemini`, atau isi `baseUrl` di settings |
| `401` | Key tidak valid untuk Triw, atau `GOOGLE_API_KEY` menimpa | Hapus `GOOGLE_API_KEY`, sisakan key Triw |
| `404` | Base URL menyertakan `/v1beta` | Gunakan host saja |
| Model diabaikan | Id tidak ada di grup Anda | Cek `GET /v1/models` |
