Triw adalah AI gateway. Anda memanggil satu endpoint dengan satu key, lalu Triw meneruskan request ke provider yang melayani model tersebut. Billing, kuota, key, dan usage semuanya ada di satu console.

```bash Base URL
https://router.triw.io
```

## Alur satu request

1. Request dikirim ke `https://router.triw.io` dengan API key (`Authorization: Bearer sk-...`).
2. Triw memetakan nama model ke channel upstream yang tersedia untuk grup key Anda.
3. Response upstream diteruskan balik dalam format yang sama seperti yang Anda kirim.
4. Pemakaian dicatat sebagai pemotongan saldo.

Yang berubah antar provider hanya nilai `model` — prompt dan parsing response tetap sama.

## Request pertama

```bash
curl https://router.triw.io/v1/chat/completions \
  -H "Authorization: Bearer $TRIW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Sapa saya dalam satu kalimat."}]
  }'
```

Daftar route lengkap — chat, messages, image, video, audio, embedding, task Midjourney — ada di [Endpoint](/id/endpoints). Job video berbasis task; lihat [Video generation](/id/video).

Baru pertama kali? Baca [quickstart](/id/quickstart) — sekitar lima menit dari daftar akun sampai token pertama keluar.
